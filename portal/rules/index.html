Event Rules Draft — edit me

Please read this page before you start. If anything here is unclear, ask an organizer rather than guessing.

Format

  • This is a blue-team / incident-response style event: you're investigating an already-compromised environment using the provided packet captures, host logs, and analysis tools.
  • Challenges are organized as a linked story. Later categories build on evidence you find in earlier ones, so work roughly in order the first time through.
  • The event runs from [start time/date] to [end time/date].

Scope

  • Stay in scope. Only exercise the targets listed on the scoreboard. Never exercise the scoreboard, organiser systems, or other teams.
  • Don't break things. No DoS, no deleting files, no patching the vuln or locking others out. Keep your scanning at a sane rate.
  • Report bugs. Found a leaked flag or a hole in the platform? Tell the organisers.

Flags & scoring

  • Submit flags on the scoreboard.
  • No brute-forcing the submit box.
  • Each challenge has a fixed point value shown on the platform; there is no dynamic/decay scoring.
  • Hints, if available, may cost points — check each challenge's description before requesting one.
  • The scoreboard is [public / frozen for the last X minutes / hidden] — state your policy here.

Submitting Answers

  • Answers are case insensitive.
  • IP addresses and ports: xyz.xyz.xyz.xyz:abcd
  • Dates and times are all ISO 8601 / RFC 3339, big-endian:
    • YYYY/MM/DD HH:MM:SS UTC
    • Or copy and paste the timestamp directly from the CTF data platform.
  • Multiple answers are comma separated: x, y, z or x,y,z
  • If you believe you have the correct answer but it won't submit — talk to event staff, don't keep guessing.

Conduct

  • Be respectful toward other participants and organizers. Harassment of any kind will result in removal from the event.
  • Don't share flags. Not with other teams, not publicly. No write-ups or spoilers until the event ends.
  • One team per person. No second accounts.
  • Organizers may adjust scoring, disqualify participants, or amend these rules if needed to keep the event fair — announcements will be posted on the platform.

Support

  • Ask for help in the support channel. Contact [support channel / email / person].
  • Include the challenge name, not the flag. Reset your container before reporting it broken.
